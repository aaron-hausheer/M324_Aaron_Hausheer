## Adding a database

I would use a separate backend API with a PostgreSQL database. The website
would call the API over HTTPS. The backend would check permissions and keep
database passwords on the server, not in the website code. The current quiz
does not need a database.

## Deployment only on tags

Yes, this is possible. My [workflow](.github/workflows/pages.yml) uses:

```yaml
on:
  push:
    tags:
      - 'v*'
```

A new tag such as `v1.0.0` triggers deployment. A push to `main` alone does
not. GitHub Actions checks out the tagged version and publishes only
`index.html` to Pages.

Pages must use **GitHub Actions** as its source, and the `github-pages`
environment must allow tags matching `v*`. My first deployment was blocked
because the environment did not allow `v1.0.0`.
